# Angina-Pectoris-Prediction

This repository contains a machine learning project focused on predicting Angina Pectoris, a type of chest pain caused by reduced blood flow to the heart. The goal is to develop a predictive model that can identify individuals at high risk of experiencing an angina pectoris based on various health and demographic features.

# Introduction
Angina Pectoris is a common symptom of coronary artery disease. Accurate prediction can help in early diagnosis and treatment, reducing the risk of severe outcomes. This project explores various machine learning algorithms to build a model that can predict the likelihood of Angina Pectoris based on patient data.

# Preprocessing
Data preprocessing steps include:

* Handling missing values.
* Encoding categorical variables.
* Normalizing numerical features.
* Splitting the dataset into training and testing sets.

# Model
Several models have been explored for Myocardial Infarction Prediction, including:

* Decision Tree
* Random Forest
* Support Vector Machine
* Logistic Regression
* Naive Bayes
* K Nearest Neighbors
* Multilayer Perceptron
* Artificial Neural Network
